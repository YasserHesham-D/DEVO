# DEVO Store — موقع المتجر الإلكتروني

موقع تجارة إلكترونية كامل لمتجر DEVO (سوهاج) مبني بـ HTML / CSS / JavaScript، وقاعدة بيانات حقيقية بصيغة SQLite تعمل بالكامل داخل المتصفح (عبر sql.js / WebAssembly) — بدون أي سيرفر أو باك-إند.

## تشغيل الموقع محليًا

المتصفحات لا تسمح لصفحة HTML مفتوحة مباشرة (file://) بتحميل ملفات WASM أو قاعدة البيانات لأسباب أمنية. لازم تشغّل سيرفر محلي بسيط، ثم تفتح الموقع من المتصفح:

**عن طريق بايثون (الأسهل):**
```
cd devo-store
python3 -m http.server 8000
```
بعدين افتح: `http://localhost:8000`

**أو عن طريق Node.js:**
```
npx serve devo-store
```

## رفع الموقع على الإنترنت (استضافة حقيقية)

الموقع بالكامل عبارة عن ملفات ثابتة (Static Files)، فممكن ترفعه مباشرة على أي استضافة زي:
- **Netlify** أو **Vercel** (اسحب المجلد وحط عليه، مجاني)
- **GitHub Pages**
- أي استضافة عادية (cPanel) — ارفع كل الملفات جوه `public_html`

لازم بس التأكد إن الاستضافة بتسمح بامتداد `.wasm` (كل الاستضافات الحديثة بتدعمه بشكل افتراضي).

## قاعدة البيانات — أهم حاجة تفهمها

قاعدة البيانات (`assets/db/devo.sqlite`) بها جدولين أساسيين: `categories` و `products`، وجدول ثالث `orders` فاضي في الأصل.

**⚠️ مهم:** لأن الموقع بيشتغل بالكامل من غير سيرفر (Static)، أي طلب (Order) بيتسجل في نسخة قاعدة البيانات اللي في **ذاكرة المتصفح فقط** (RAM)، مش بيتكتب فعليًا في ملف `devo.sqlite` على السيرفر. يعني لو العميل قفل المتصفح، الطلب ده مش هيبقى موجود في الملف الأصلي.

**عشان كده الموقع بيعمل حاجتين مع كل طلب:**
1. بيسجل الطلب في قاعدة البيانات المؤقتة (تقدر تصدّرها لو حبيت).
2. بيدّي العميل زرار "أكّد عبر واتساب" يبعتلك رسالة فيها رقم الطلب على رقمك مباشرة — وده المصدر الحقيقي اللي تعتمد عليه لتنفيذ الطلبات فعليًا.

**لو حبيت تشوف/تصدّر الطلبات اللي حصلت في جلسة معينة:** في أسفل الموقع (Footer) في رابط "تصدير قاعدة البيانات" — بيحمّل نسخة `.sqlite` فيها كل الطلبات اللي حصلت في نفس الجلسة، وتقدر تفتحها بأي برنامج SQLite (زي DB Browser for SQLite، مجاني).

**لو عايز حل دائم للطلبات (يُنصح به لمتجر شغال فعليًا):** الخطوة الجاية الطبيعية هي ربط فورم الـ Checkout بخدمة بسيطة زي Google Sheets عبر Google Forms، أو باك-إند بسيط (Node/PHP) يكتب الطلبات في قاعدة بيانات حقيقية على السيرفر. أنا جاهز أساعدك في أي منهم لو حبيت تتوسع.

## تعديل المنتجات أو الأسعار

أسهل طريقة: افتح `build_db.py` بأي محرر نصوص، عدّل في قائمة `products_data` (الاسم، الفئة، السعر، الألوان)، وبعدين شغّل:
```
python3 build_db.py
```
هيعيد بناء `assets/db/devo.sqlite` بالتعديلات الجديدة. (يحتاج بايثون مع مكتبة `sqlite3` المدمجة أصلاً).

## ملاحظات تقنية أخرى

- **السلة والمفضلة**: محفوظة في `localStorage` بتاع المتصفح، يعني تفضل موجودة حتى لو العميل قفل المتصفح وفتحه تاني (على نفس الجهاز).
- **الشحن المجاني**: مفعّل تلقائيًا للطلبات فوق 1,500 ج.م (تقدر تغيّر الرقم ده في `js/cart.js` داخل دالة `totals()`).
- **رقم الواتساب/الهاتف**: موجود في `js/app.js` أعلى الملف داخل كائن `STORE` — غيّره من مكان واحد بس لو الرقم اتغيّر.
- **الخطوط**: الموقع بيحمّل خطوط Cairo و Tajawal من Google Fonts، فلازم يكون فيه اتصال إنترنت عادي عشان تظهر الخطوط بشكل صحيح (لو الإنترنت مقطوع هيرجع لخط افتراضي عادي، الموقع هيفضل شغال عادي بس الخط هيبقى مختلف شوية).
